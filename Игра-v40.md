# Фон локаций и точный масштаб v40

В библиотеку добавлены 33 карты из «Загрузок». Оригиналы не изменены. Игровые копии сохраняют пропорции; масштаб задаётся одним коэффициентом метров на пиксель для обеих осей.

## Как включить карту

1. Ведущий: «Бой» → включить «Режим редактирования» → «Фон локации и масштаб · ведущий».
2. Выбрать изображение и раскрыть «Калибровка масштаба».
3. Отметить два ориентира. Для сетки ориентир — 5 м на клетку; лучше отметить 10 клеток и ввести 50 м. Можно приблизить картинку и сдвинуть её для точного выбора точек. Для карты без сетки потребуется известное расстояние между ориентирами.
4. Нажать «Сохранить масштаб», проверить показанные ширину и высоту карты в метрах, затем «Показать в текущей сцене».
5. Включить «Расстановка ведущего» и поставить фигурки в нужные места. Настройки ведущего скрываются при выключении режима редактирования.

Название файла «22×17» само по себе не используется как метры или число клеток: на изображении могут быть поля. Без сохранённой калибровки включить карту для боя нельзя. Масштаб и фон меняются между боями; повторная калибровка сохраняет физические координаты фигурок, поэтому после изменения масштаба проверь их расстановку.

Приближение, сдвиг и размер экрана меняют только отображение. Изображение, фигурки, линейка и радиус заклинания используют одну систему координат. Верхний левый угол изображения — начало координат; вправо X растёт, вниз Y уменьшается. В обычной игре координаты вводить не нужно.

Фон назначается текущей сцене; без текущей сцены используется общий стол. Расстановка запоминается отдельно для каждой пары «сцена + карта», когда уходите с неё. При возвращении восстанавливается. Поле без фона тоже сохраняет свою расстановку.

Стены, предметы и укрытия на рисунке пока декоративные — они ещё не блокируют движение или атаки.

## Файлы карт

Изображения хранятся локально в `components/tactical_map/maps/`. Они загружаются браузером как обычные ресурсы, не пересылаются заново с каждым действием. Код синхронизируется с GitHub; набор изображений находится в отдельном локальном архиве `Карты-для-Калисты-v40.zip`. Для другой установки распакуйте архив рядом с `kalista_app.py` с сохранением структуры папок.

## Проверка

21 набор проверки механик и интерфейса. Добавлены проверки единого коэффициента по обеим осям, диагонали, повреждённой калибровки, запрета включения фона без масштаба, обоих ролей и режимов, сохранения расстановок при смене и завершении сцен. Контрольная калибровка и расстановка проверены в отдельной тестовой копии; фон проверен на ширине экрана 390 px. В основную игру тестовые метры и расстановка не переносились.
