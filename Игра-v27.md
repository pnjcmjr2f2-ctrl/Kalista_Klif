# Игра v27

После окончания боя снимаются щиты всех участников. Поверженные враги скрываются из списков боевых целей сразу при HP 0; при завершении боя убираются из действующих участников, запись сохраняется в defeated_enemies для будущей системы наград. Журнал и история отмены сохраняются. Живые враги и поверженные союзники не удаляются.
Удалена справка о двуручном мече из раздела «Отряд».
В обзоре Калисты отображается общий опыт относительно записанного следующего порога (текущий XP + оставшийся XP). Для Шеогарата показывается сохранённый опыт; пока числовой порог не задан, прогресс не вычисляется и это явно подписано. Награды за врагов не начисляются.
