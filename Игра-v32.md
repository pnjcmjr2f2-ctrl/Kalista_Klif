# Игра v32 — редкость и случайная добыча

Пять категорий: Обычный, Необычный, Редкий, Эпический, Легендарный. Есть цветные метки и фильтр редкости в обычном просмотре вещей. Редкость существующего предмета сама не меняет его бонусы.
Калиста: теневая броня редкая, фамильный амулет эпический, посох легендарный, серьги и кольца необычные. Шеогарат: Ледяная скорбь легендарная, второй меч редкий, обычная броня обычная, Ниргхал легендарный. Числовые свойства Ниргхала берутся из сохранённой карточки, а не из категории редкости.

Случайная добыча — процедурные шаблоны расходников, материалов, оружия и брони. Не нужно создавать отдельную запись для каждого возможного предмета. Из каждого побеждённого врага выпадает максимум один предмет: обычный 25%, элитный 50%, босс 100%. Результат определяется ID боя и врага; повторное завершение и отмена/повтор завершения не меняют бросок.
Сгенерированные свойства — предложения для ведущего. На странице «Бой» можно выдать предмет Калисте или Шеогарату либо отклонить. В режиме редактирования можно скорректировать название, количество, редкость, описание и числа. Выдача однократная. Расходники/материалы попадают в инвентарь, оружие/броня — в резерв. Надевание из резерва заменяет вещь в соответствующей ячейке, прежняя вещь сохраняется.
Уровень создаваемых свойств ограничен максимумом уровней участников на старте +5. Процедурные предметы не получают названия или свойства уникальных комплектов Ниргхала и именных артефактов.
Ведущий → режим редактирования → настройки случайной добычи: шансы и относительные веса категорий, отдельно для обычных, элитных и боссов. Веса по умолчанию: 70/22/6/1,8/0,2; 45/35/15/4,5/0,5; 10/30/40/18/2. Настройки фиксируются на старте боя.
