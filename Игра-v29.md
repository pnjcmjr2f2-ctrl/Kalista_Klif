# Игра v29 — режим редактирования

Переключатель «Режим редактирования» в боковом меню ведущего и игрока. По умолчанию выключен, действует только для своего экрана. В обычном режиме отображаются характеристики, вещи, способности, записи и сцены без форм правки. Настройки и административные поля доступны после включения.
Боевые действия, перемещение, подтверждение предложений, применение расходников и особых умений Калисты остаются доступными без включения редактирования. Числовые поправки урона, эффекты вручную, настройки очереди и импорта скрыты.
Бэкап перед изменением: «Бэкап-перед-режимом-редактирования-v28.zip», содержит прежний код, сохранение, конфигурацию и ключи доступа. Для возврата остановить приложение и распаковать бэкап поверх папки приложения, затем запустить снова. Сначала сохранить актуальную игру, если её нужно оставить.
