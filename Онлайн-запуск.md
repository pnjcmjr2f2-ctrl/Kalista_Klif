# Калиста — запуск с рабочего стола

На рабочем столе созданы три файла:

- **Калиста — включить онлайн.command** — двойной щелчок запускает приложение и туннель, показывает адреса и открывает игру в браузере. Подожди до минуты. Если соединение уже работает, используется прежняя ссылка.
- **Калиста — адреса подключения.command** — показывает актуальную интернет-ссылку, локальный IP и адрес для этого компьютера.
- **Калиста — выключить онлайн.command** — отключает внешний доступ. Локальная игра продолжает работать.

Интернет-ссылка записана также в `Онлайн-доступ.txt` в папке приложения. Для друга из другой сети нужна строка HTTPS. Для устройств в той же Wi-Fi сети — локальный IP с портом 8501. IP VPN для подключения к игре не используется.

Закрытие окна Терминала после запуска не выключает приложение или туннель. Пока туннель работает, компьютер защищён от автоматического сна при бездействии; принудительный сон, выключение и закрытие крышки всё равно прервут доступ. VPN оставляй включённым.

После перезапуска туннеля или истечения адреса у бесплатного сервиса ссылка может измениться — открой ярлык с адресами и отправь новую. Если ссылка перестала работать, выключи онлайн отдельным ярлыком, затем включи снова.

Не перемещай и не удаляй папки проекта `outputs` и `work`: ярлыки используют установленное приложение и Python из них. Вход по прежним ключам; другу нужен только ключ игрока.
