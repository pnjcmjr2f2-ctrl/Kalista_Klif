# Игра v30 — опыт за бой

Базовая награда обычного врага: округлить(5 × уровень врага^1,2). Элитный ×2, босс ×5 (не складывается с элитным).
Участники и уровни героев фиксируются на старте боя: живые Калиста и Шеогарат, не исключённые из очереди. Потерявший HP во время боя остаётся получателем. Сумма делится на количество зафиксированных участников, доля округляется вниз.
Для каждого героя отдельно: враг на 10+ уровней ниже — 0 XP. На 15+ уровней выше — уровень награды ограничен уровнем героя +14, затем применяется ×25%. Обычный враг 21 уровня: общая база 193 XP, по 96 XP при двух участниках.
Награды выдаются по кнопке «Стоп» за побеждённых врагов, включая периодический урон и контратаки. Выжившие враги при отступлении не дают XP. Старые поверженные враги, архив, дружественные и нейтральные NPC не дают XP. Для врага без уровня награда 0 с пояснением; уровень и элитность/босс настраиваются в режиме редактирования участника. Подкрепления учитываются.
Каждый бой имеет уникальный ID и отметку начисления; повторное завершение не выдаёт XP. Результат сохраняется и виден ведущему после перезагрузки; игрок видит свою итоговую награду.
Повышение уровня автоматическое: +4 очка за каждый уровень, избыток переносится, потолок 1650. Автоматического лечения при повышении нет. Награды за предметы не добавлены.
Учёт начинается с новых боёв; бой, начатый до обновления, не получает ретроспективную награду без зафиксированного состава.
